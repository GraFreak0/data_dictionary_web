## 🔄 Request Flow

### Search Request Flow

```
User enters search → Frontend validates → API call with JWT
                                            │
                                            ▼
                             Flask receives request
                                            │
                                            ▼
                          Validate JWT token
                                            │
                                            ▼
                          Check user permissions
                                            │
                                            ▼
                        Load YAML files from disk
                                            │
                                            ▼
                    Filter based on user's permissions
                                            │
                                            ▼
                       Search across tables/columns
                                            │
                                            ▼
                         Return filtered results
                                            │
                                            ▼
                        Frontend displays results
```

### Permission Check Flow

```
User requests resource → Extract user ID from JWT
                              │
                              ▼
                        Is user admin?
                              │
                    ┌─────────┴─────────┐
                   YES                  NO
                    │                    │
                    ▼                    ▼
               Allow access     Query permissions table
                                        │
                                        ▼
                          Does user have permission
                          for this resource?
                                        │
                              ┌─────────┴─────────┐
                             YES                  NO
                              │                    │
                              ▼                    ▼
                         Allow access        Deny (403)
```

## 📦 Component Breakdown

### Frontend (SPA - Single Page Application)

**Technology:** Vanilla JavaScript (no frameworks)

**Components:**
1. **Login Page** (`/`)
   - Username/password form
   - JWT token retrieval
   - Session creation

2. **Main Search Interface** (`/`)
   - Search bar with filters
   - Real-time search
   - Results display
   - Table details modal

3. **Admin Panel** (`/admin`)
   - User list table
   - Create user form
   - Permission management
   - Activity viewer

**State Management:**
- Current user stored in JavaScript
- JWT token in memory (not localStorage for security)
- Session managed by Flask

### Backend (Flask Application)

**Technology:** Python Flask + Extensions

**Modules:**

1. **Authentication (`/api/auth/*`)**
   - `login` - Authenticate user, return JWT
   - `logout` - Invalidate session
   - `me` - Get current user info

2. **Search (`/api/search`)**
   - Load YAML files
   - Parse metadata
   - Filter by permissions
   - Return matching results

3. **Browse (`/api/schemas/*`)**
   - List schemas user can access
   - List tables in schema
   - Get table details with columns

4. **Admin (`/api/admin/*`)**
   - User CRUD operations
   - Permission CRUD operations
   - Activity log retrieval

5. **Statistics (`/api/stats`)**
   - Count accessible schemas/tables/columns

**Security Layers:**
```python

@login_required           # Must be logged in
@role_required('admin')   # Must be admin
def get_users():
    # Function logic
```

### Database (SQLite)

**Schema:**

```sql
-- Users table
users (
    id INTEGER PRIMARY KEY,
    username TEXT UNIQUE,
    email TEXT UNIQUE,
    password_hash TEXT,
    role TEXT,
    created_at TIMESTAMP,
    last_login TIMESTAMP,
    is_active BOOLEAN
)

-- Permissions table
permissions (
    id INTEGER PRIMARY KEY,
    user_id INTEGER,
    resource_type TEXT,    -- 'database' or 'table'
    resource_name TEXT,    -- 'production' or 'schema.table'
    permission_level TEXT, -- 'read', 'write', 'admin'
    created_at TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
)

-- Activity log
activity_log (
    id INTEGER PRIMARY KEY,
    user_id INTEGER,
    action TEXT,
    resource_type TEXT,
    resource_name TEXT,
    timestamp TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
)
```

## 🔐 Security Architecture

### Authentication Flow

```
1. User submits credentials
   ↓
2. Hash password and compare with stored hash
   ↓
3. Generate JWT token (24hr expiry)
   ↓
4. Return token to client
   ↓
5. Client includes token in all requests
   ↓
6. Server validates token on each request
```

### Authorization (RBAC) Model

```
┌─────────────────────────────────────────┐
│              User                        │
│  - id                                    │
│  - username                              │
│  - role: admin | contributor | viewer    │
└─────────────┬───────────────────────────┘
              │
              │ has many
              ▼
┌─────────────────────────────────────────┐
│           Permission                     │
│  - resource_type: database | table       │
│  - resource_name: "production"           │
│  - permission_level: read | write | admin│
└──────────────────────────────────────────┘
```

**Permission Hierarchy:**
```
admin role
  └─ Full access to everything
     └─ Bypasses permission checks

contributor role
  └─ Access based on permissions
     └─ Can read/write assigned resources

viewer role
  └─ Access based on permissions
     └─ Can read assigned resources
```

### Data Flow Security

```
Request → HTTPS → Nginx → Flask
                            │
                            ▼
                     Check JWT validity
                            │
                            ▼
                     Check user role
                            │
                            ▼
                  Check resource permissions
                            │
                            ▼
                    Filter data by permissions
                            │
                            ▼
                   Return only accessible data
```

## 📊 Data Flow

### YAML File Processing

```
YAML Files on Disk
      │
      ▼
Load into memory (on demand)
      │
      ▼
Parse YAML structure
      │
      ▼
Extract metadata:
  - Schemas
  - Tables
  - Columns
  - Data types
  - Constraints
      │
      ▼
Filter by user permissions
      │
      ▼
Return to frontend
```

### Search Algorithm

```python
def search_metadata(query, user_id, filters):
    1. Load all YAML files
    2. For each schema:
        a. Check if user has access to schema
        b. If yes, continue; if no, skip
    3. For each table in accessible schemas:
        a. Check if query matches table name
        b. Check if query matches table description
        c. For each column:
            - Check if query matches column name
            - Check if query matches column description
    4. Collect all matches
    5. Apply filters (schema, table_type)
    6. Return results
```
