## 🔐 Security Architecture

### Authentication Flow

```
┌──────────┐
│  Client  │
└────┬─────┘
     │ 1. POST /api/auth/login
     │    {username, password}
     ▼
┌─────────────────┐
│  Flask Server   │
└────┬────────────┘
     │ 2. Hash password & compare
     │ 3. Generate JWT token (24hr expiry)
     ▼
┌──────────────────────────────────┐
│  JWT Token                        │
│  {                                │
│    user_id: 1,                    │
│    username: "john",              │
│    role: "viewer",                │
│    exp: timestamp + 24hr          │
│  }                                │
│  Signed with JWT_SECRET_KEY       │
└──────────────────────────────────┘
     │ 4. Return token to client
     ▼
┌──────────┐
│  Client  │ Stores token in memory
└──────────┘ Sends in Authorization header
```

### Authorization Flow (With Groups)

```
User requests resource → Extract JWT → Get user_id & role
                                           │
                                           ▼
                                    Is user admin?
                                           │
                            ┌──────────────┴──────────────┐
                           YES                            NO
                            │                              │
                            ▼                              ▼
                      ALLOW ACCESS              Check Individual Permissions
                                                          │

                                                 HAS              NO
                                                  │                │
```

## 🔄 Request Flow Examples

### Example 1: Search with Group Permissions

```
User: john (member of "Data Team" group)

1. User searches for "customer"
   GET /api/search?q=customer

2. Server extracts JWT → user_id=5, role=viewer

3. Check permissions:
   a. Is admin? NO
   b. Individual permissions? 
      - database: staging (read)
   c. Group permissions? (via "Data Team")
      - database: production (read)
      - database: analytics (read)
   
4. Combined accessible resources:
   - staging
   - production  
   - analytics

5. Search YAML files:
   - schema_staging.yml ✓ (accessible)
   - schema_production.yml ✓ (accessible)
   - schema_analytics.yml ✓ (accessible)
   - schema_finance.yml ✗ (not accessible - skip)

6. Return filtered results:
   - customer table in production
   - customer_events table in analytics
   - (no results from finance - user can't see it)
```

### Example 2: PDF Export

```
User: sarah (contributor, can_export=True)

1. User clicks "Export PDF"
   POST /api/export/pdf
   Body: {type: "full"}

2. Server checks:
   a. Is user logged in? YES
   b. Does user have export permission? YES (can_export=True)

3. Get accessible resources:
   - Individual: production (read)
   - Group "Analysts": analytics (read), staging (read)
   - Combined: production, analytics, staging

4. Generate PDF:
   - Load YAML files
   - Filter by accessible resources only
   - Create PDF with ReportLab
   - Include metadata (user, timestamp)

5. Log export:
   - INSERT INTO export_log (user_id, export_type, resources_exported)

6. Return PDF file to download

User: bob (viewer, can_export=False)

1. User clicks "Export PDF" → Button not shown (disabled in UI)
2. If user tries API directly:
   POST /api/export/pdf
   
3. Server checks:
   a. Is user logged in? YES
   b. Does user have export permission? NO (can_export=False)
   
4. Return 403 Forbidden
   {error: "Export permission required"}
```

## 📊 Permission Resolution Algorithm

```python
def has_access(user_id, resource_type, resource_name):
    """
    Determines if user has access to a resource.
    Priority: Admin > Individual Permissions > Group Permissions
    """
    
    # Step 1: Check if admin
    user = get_user(user_id)
    if user.role == 'admin':
        return True  # Admin has access to everything
    
    # Step 2: Check individual permissions
    individual_perm = db.query(
        "SELECT * FROM permissions WHERE user_id=? AND resource_type=? AND resource_name=?",
        (user_id, resource_type, resource_name)
    )
    if individual_perm:
        return True  # Has direct permission
    
    # Step 3: Check group permissions
    group_perm = db.query("""
        SELECT gp.* FROM group_permissions gp
        JOIN user_group_members ugm ON gp.group_id = ugm.group_id
        WHERE ugm.user_id=? AND gp.resource_type=? AND gp.resource_name=?
    """, (user_id, resource_type, resource_name))
    if group_perm:
        return True  # Has permission through group
    
    # Step 4: No permissions found
    return False  # Access denied
```
